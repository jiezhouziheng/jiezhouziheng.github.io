面试总结-模拟面试02

发表于 2026-06-01 分类于 实习准备

模拟面试二（5/25）

这一次依然是朋友作为面试官的模拟面试。这次由于暂定方向为 Agent 开发，所以面试官主要考查的是我的 Agent 项目和 Agent 相关知识，还涉及一些真实工程里的细节问题。当然也是基本没有答出来，但是感觉上比第一次好一些，没有那么紧张，基于项目也能说个几句，不至于一句话都答不上来。

流程上大概还是先第一轮基于项目聊聊八股，看看理解情况。大概二十分钟后开始悄然进入第二轮技术问答，问题开始偏向工程化、细节化。考虑到现在有很多 Agent 开发手撕方面不是特别要求，而且这次时间上比较紧张，所以没有安排手撕，第二轮问了一下就进入提问环节，结束了（没有手撕还是令人松了口气）。

复盘面试，还是存在一些比较严重的问题。在问到项目的数据流时，我的回答应该偏离了，所以面试官打断了并换了个问法，问整个使用过程中数据经过了哪些模块。后面又问到 paper-id 的生成以及并发问题，好家伙我完全没有考虑并发的情况，id 的生成逻辑也只是时间戳加上一串随机数，只是保证了 id 的唯一性，但是多个用户同时请求的并发情况我没有想到。于是和面试官驴唇不对马嘴地聊了一会儿，面试官才意识到我完全没考虑并发，呵呵怪尴尬的。

项目算一个 Agent 项目吗？相对于成熟的 Agent 项目，我的 demo 还欠缺什么？这里简单回答了 LLM 的调用以及 RAG 还没做。又问 pytest 测试怎么做的？举例说明。这里我举了 chunking 部分的测试例子，因为这部分测试在写项目的时候是发现过问题的，第一遍测试发现 chunk 分割有问题，所以这部分我的印象比较深。

比较搞的是我这个项目就是小 demo，小的不能再小，所以稍稍复杂点的情况我都没考虑。比如这里问前端怎么处理后端的报错，我是只在前端加了一个后端健康状态的显示，但是问用户网络出问题的情况，我还不知道。问关键词检索的实现、有没有参考优秀开源项目等。这里我发散了一下，讲了我对关键词检索和向量检索的初级理解，不管是不是废话，好歹是说了一会儿。

哎提到了向量检索，面试官就问向量检索中余弦相似度的计算？我项目甚至还没到 RAG 那一步，这些啥也不会，直接把几个相关问题都说不会跳过了。接着就问啊，PDF 解析。这里我不知道 PDF 里表格和公式在业内是单独处理，我直接把这些当普通文本说，也是无知了。以及在服务器上部署这个项目的相关细节问题。这种问题如果没有实际部署过很难回答得很好，我没部署过，也缺乏工程思维，在问到权限问题以及安全问题的时候完全不会回答。还有并发方面的考虑很重要，没有并发考虑的项目是没有业务价值的。

嗯这次面试问题很明显，缺乏工程常识，相关八股基本不会，项目太简陋且阐述不够清晰。继续努力！
